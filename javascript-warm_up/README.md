# JavaScript - Warm up

This directory contains solutions for the **JavaScript - Warm up** project as part of the ALU Software Engineering curriculum.

## Requirements
- All files are interpreted on Ubuntu 20.04 LTS using `node` (version 14.x).
- All files start with `#!/usr/bin/node`.
- All files are `semistandard` compliant (version 16.x.x).
- All files end with a newline and are executable.

## Tasks

| Task | File | Description |
|---|---|---|
| 0 | `0-javascript_is_amazing.js` | Prints "JavaScript is amazing" |
| 1 | `1-multi_languages.js` | Prints 3 lines of different languages |
| 2 | `2-arguments.js` | Prints message based on number of arguments |
| 3 | `3-value_argument.js` | Prints the first argument passed |
| 4 | `4-concat.js` | Prints two arguments formatted as `<arg1> is <arg2>` |
| 5 | `5-to_integer.js` | Converts first argument to an integer |
| 6 | `6-multi_languages_loop.js` | Prints 3 lines using an array and a loop |
| 7 | `7-multi_c.js` | Prints "C is fun" x times |
| 8 | `8-square.js` | Prints a square of size x using character X |
| 9 | `9-add.js` | Prints addition of 2 integers using a function |
| 10 | `10-factorial.js` | Computes and prints a factorial recursively |
| 11 | `11-second_biggest.js` | Finds the second biggest integer in argument list |
| 12 | `12-object.js` | Updates object value property from 12 to 89 |
| 13 | `13-add.js` | Exported function that returns addition of 2 integers |
