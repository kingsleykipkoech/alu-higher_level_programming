# JavaScript - Web scraping

This directory contains solutions for the **JavaScript - Web scraping** project as part of the ALU Software Engineering curriculum.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- All files are interpreted on Ubuntu using `node` (version 10.14.x / 14.x / 20.x).
- All files start with `#!/usr/bin/node`.
- All files are `semistandard` compliant (Rules of Standard + semicolons on top).
- All files must be executable.
- All files end with a new line.
- You are not allowed to use `var`.

## Tasks

| Task | File | Description |
|---|---|---|
| 0 | `0-readme.js` | Reads and prints the content of a file in UTF-8 |
| 1 | `1-writeme.js` | Writes a string to a file in UTF-8 |
| 2 | `2-statuscode.js` | Displays the status code of a GET request using `request` |
| 3 | `3-starwars_title.js` | Prints the title of a Star Wars movie where episode number matches a given integer |
| 4 | `4-starwars_count.js` | Prints the number of movies where the character "Wedge Antilles" is present |
| 5 | `5-request_store.js` | Gets the contents of a webpage and stores it in a file |
| 6 | `6-completed_tasks.js` | Computes the number of tasks completed by user id |
