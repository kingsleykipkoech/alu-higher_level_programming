# JavaScript - Web jQuery

This directory contains solutions for the **JavaScript - Web jQuery** project as part of the ALU Software Engineering curriculum.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- All files will be interpreted on Chrome (version 57.0).
- All files should end with a new line.
- A `README.md` file, at the root of the folder of the project, is mandatory.
- Your code should be semistandard compliant with the flag `--global $`: `semistandard *.js --global $`.
- You must use jQuery version 3.x.
- You are not allowed to use `var`.
- HTML should not reload for each action: DOM manipulation, update values, fetch data...

## Tasks

| Task | File | Description |
|---|---|---|
| 0 | `0-script.js` | Updates the text color of the `<header>` element to red (`#FF0000`) using `document.querySelector` |
| 1 | `1-script.js` | Updates the text color of the `<header>` element to red (`#FF0000`) using jQuery |
| 2 | `2-script.js` | Updates text color of `<header>` to red (`#FF0000`) when clicking `DIV#red_header` |
| 3 | `3-script.js` | Adds the class `red` to `<header>` when clicking `DIV#red_header` |
| 4 | `4-script.js` | Toggles the class of `<header>` between `red` and `green` when clicking `DIV#toggle_header` |
| 5 | `5-script.js` | Adds a `<li>Item</li>` to `UL.my_list` when clicking `DIV#add_item` |
| 6 | `6-script.js` | Updates text of `<header>` to "New Header!!!" when clicking `DIV#update_header` |
| 7 | `7-script.js` | Fetches character name from Star Wars API and displays it in `DIV#character` |
| 8 | `8-script.js` | Fetches all movie titles from Star Wars API and lists them in `UL#list_movies` |
| 9 | `9-script.js` | Fetches greeting from HelloSalut API and displays in `DIV#hello`, executed on DOM load |
