# Python - Everything is object

This directory contains answers to conceptual questions about Python's object model, focusing on identity, type, mutability, and how arguments are passed to functions.

## Tasks

* **0. Who am I?**: Function to print the type of an object (`type`).
* **1. Where are you?**: Function to get the variable identifier (`id`).
* **2. Right count**: Memory comparison for different integers.
* **3. Right count =**: Memory comparison for same small integers.
* **4. Right count =**: Memory comparison for variable assignments.
* **5. Right count =+**: Memory comparison for integer addition.
* **6. Is equal**: Value comparison of variables referencing the same string object.
* **7. Is the same**: Identity comparison of variables referencing the same string object.
* **8. Is really equal**: Value comparison of identical string literals.
* **9. Is really the same**: Identity comparison of identical string literals.
* **10. And with a list, is it equal**: Value comparison of identical list literals.
* **11. And with a list, is it the same**: Identity comparison of identical list literals.
* **12. And with a list, is it really equal**: Value comparison of list assignment.
* **13. And with a list, is it really the same**: Identity comparison of list assignment.
* **14. List append**: Side effects of list append on alias variables.
* **15. List add**: Side effects of list addition assignment on alias variables.
* **16. Integer incrementation**: Passing immutable objects to functions.
* **17. List incrementation**: Passing mutable objects to functions.
* **18. List assignation**: Re-assigning references within functions.
* **19. Copy a list object**: Function `copy_list` returning a copy of a list.
* **20. Tuple or not?**: Empty tuple.
* **21. Tuple or not?**: Two-element tuple.
* **22. Tuple or not?**: Non-tuple parentheses grouping.
* **23. Tuple or not?**: Single-element tuple.
* **24. Who I am?**: Identity comparison of non-tuples.
* **25. Tuple or not**: Identity comparison of two identical tuples.
* **26. Empty is not empty**: Identity comparison of two empty tuples.
* **27. Still the same?**: Identity check for list concatenation (`+`).
* **28. Same or not?**: Identity check for list addition assignment (`+=`).
